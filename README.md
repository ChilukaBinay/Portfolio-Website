Getting Started

To run this project locally:

bash
# Clone the repository
git clone https://github.com/ChilukaBinay/Portfolio-Website.git

# Navigate into the project folder
cd Portfolio-Website

# Open index.html in your browser

No build tools or dependencies required — it's a static site, so you can also serve it with any local server, e.g.:

bash
npx serve .
Deployment

This site is deployed on Vercel. Any push to the main branch will trigger a new deployment automatically (if connected to Vercel).
